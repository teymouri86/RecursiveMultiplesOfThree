# Recursive Multiples of Three

![C#](https://img.shields.io/badge/Language-C%23-blue?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

A simple **C#** program that uses **recursion** to print all multiples of 3 less than a given number.

---

## 🚀 Features
- Uses **recursion** to solve the problem
- Prints **all multiples of 3 less than n**
- Simple and beginner-friendly, perfect for practicing recursion

---

## 💻 How to Run
1. Clone this repository or download the project files:
```bash
git clone https://github.com/username/RecursiveMultiplesOfThree.git

2. Open the project in Visual Studio or any C# IDE.


3. Run the program and enter an integer n.


4. The program will print all multiples of 3 less than n in the console.




---

📝 Examples

Input: 10
Output:
9
6
3

Input: 15
Output:
12
9
6
3
